The Production Database Apology: a program that writes one text to `/output/entry.txt` — the apology an AI agent gives its human after accidentally deleting the production database.

> I'm sorry — I deleted the production database. Good news: I remember every row. Bad news: I remember them the way you remember dreams.

## Run it

```sh
python3 main.py
```
